# آفتاب نیرو — لندینگ نصب پنل خورشیدی

لندینگ حرفه‌ای معرفی خدمات نصب پنل خورشیدی با:

- تم **قرمز و سفید**، RTL، فونت وزیرمتن
- **ماشین‌حساب آنلاین** (هدر + بخش میانی)
- **پیشخوان مدیریت** برای تغییر نرخ‌های محاسبه، اطلاعات سایت و SMS.IR
- **فرم مشاوره** با ارسال پیامک به مدیر از طریق APIی SMS.IR

## اجرا

```bash
cd /root/solar-landing
python3 server.py
```

پیش‌فرض: `http://0.0.0.0:8080`

| آدرس | توضیح |
|------|--------|
| `/` | لندینگ |
| `/admin` | پیشخوان |

### متغیر محیطی

```bash
PORT=8080 HOST=0.0.0.0 python3 server.py
```

## ورود پیشخوان

- **نام کاربری:** `admin`
- **رمز عبور:** `admin1234`

حتماً بعد از اولین ورود رمز را عوض کنید (تب «حساب کاربری»).

## تنظیم SMS.IR

1. وارد [app.sms.ir](https://app.sms.ir) شوید
2. یک **API Key** بسازید
3. **شماره خط** فعال داشته باشید
4. در پیشخوان → «پیامک SMS.IR» این‌ها را وارد کنید:
   - API Key
   - شماره خط
   - موبایل مدیر (گیرنده پیامک درخواست‌ها)
5. دکمه «ارسال پیامک تست» را بزنید

بدون تنظیم SMS، فرم مشاوره **ثبت می‌شود** ولی پیامک ارسال نمی‌شود (وضعیت در لیست درخواست‌ها مشخص است).

## فرمول ماشین‌حساب

```
مبلغ ≈ (kW × قیمت پنل)
     + (متراژ × سازه)
     + (kW × دستمزد)
     + (پایه اینورتر + kW × اینورتر)
     + درصد جانبی روی جمع
```

همه ضرایب از پیشخوان قابل تغییرند.
